# 🍴 College Resto – Interactive Restaurant Landing Page

**College Resto** is an interactive restaurant landing page built using **HTML, CSS, and JavaScript**.  
It features a dynamic hero section that updates in real time based on the selected food item from the menu.

This project is perfect for **beginners** looking to improve their **frontend development skills** through **JavaScript event handling** and **UI interactions**.

---

## 🌟 Features
- 🎨 Beautiful and responsive UI design  
- 🍔 Dynamic hero section that updates with selected food items  
- ⚡ Smooth animations and transitions for better UX  
- 🧭 Simple and clean navigation  
- 💻 Beginner-friendly project to practice HTML, CSS & JS  

---

## 🛠️ Technologies Used
- **HTML5** – Page structure  
- **CSS3** – Styling and responsive design  
- **JavaScript (ES6)** – Interactivity and dynamic content updates
